EFS Attend

Android · iOS

EFS Attend is a mobile attendance management application built for field-based and on-site teams. The app enables team leads to manage their teams by adding users and registering facial data directly within the application. Attendance is marked using face recognition by capturing a single image, eliminating the need for manual check-ins. Face recognition is integrated using on-device machine learning to ensure fast and reliable performance. The application follows an offline-first approach, allowing attendance to be recorded even without an internet connection. All offline data is securely stored in a local database for up to 45 days and automatically synced when connectivity is restored. Location-based geofencing ensures attendance can only be marked within approved work areas. To prevent misuse, the app blocks attendance marking if the device time is not properly synchronized. The solution is developed in Flutter and supports both Android and iOS platforms.

RF Pro

Android · iOS

RF Pro is a restaurant management application designed to help waiters and floor managers manage orders, tables, and daily restaurant operations from one place. Restaurant staff can log in using their email and password or use a 4-digit PIN for faster access during busy operations. Waiters can create orders, assign tables, add items to existing orders, customize items with extras and toppings, add tips, and print receipts directly from the application. Floor managers have additional controls to change table and waiter assignments and modify orders when required. Each restaurant table has a unique QR code that customers can scan to check their order status and request assistance from the assigned waiter. When a customer calls a waiter, the assigned waiter receives a push notification identifying the table that needs assistance. Customers can also submit feedback through the application based on their dining experience. The application supports pre-booked orders, allowing staff to mark customers as arrived and continue the normal order process. Sensitive order modifications are protected with a secure PIN to prevent unauthorized changes. RF Pro works across mobile and tablet devices and is connected with the RF Pro CP application to manage the complete restaurant order workflow.

RF Pro CP

Android · Windows

RF Pro CP is a restaurant kitchen and cashier management application designed for Windows desktop and tablet devices. Orders created through RF Pro are sent to the appropriate kitchen where staff can manage incoming orders and update their status from cooking to served. Kitchen staff can switch between multiple kitchens when a restaurant has separate kitchen operations. The kitchen screen includes timers for complete orders as well as individual items, including items added to an existing order later. The application also includes a complete cashier system for managing running orders, collecting payments, applying discounts, and completing orders. Cashiers can temporarily hold orders and continue processing them later without losing the order details. Orders can be filtered using dynamically configured categories such as dine-in, takeaway, and delivery platforms such as Foodpanda. Payment methods and discount options are dynamic, allowing the restaurant to support different payment types such as cash and card. Cashiers can print receipts, manage completed and running orders, and print receipts for previous orders. The register system allows cashiers to open the register at the start of the day and close it at the end, with transactions handled while the register is open. Cashiers can export order reports containing completed and running orders along with their total values. RF Pro CP is connected with RF Pro through REST APIs and works as part of the same restaurant management ecosystem.
